# Perimetre fonctionnel V1

## Utilisateur

Un seul utilisateur : le freelance proprietaire des donnees.

## Usage principal

Application visuelle simple, utilisee localement. Le choix entre application
desktop et application web locale reste ouvert.

## Dans le perimetre

- creer, consulter, modifier et archiver une fiche prospect ;
- regrouper entreprise, contact principal et opportunite dans une fiche unique ;
- affecter un statut commercial ;
- calculer un score de qualification explicable ;
- corriger manuellement ce score ;
- conserver une chronologie detaillee des evenements ;
- planifier et suivre les relances ;
- afficher les relances en retard, les actions du jour et les actions a venir ;
- associer une categorie d'offre indicative ;
- cloturer une prospection comme gagnee, perdue ou a ne plus contacter ;
- rechercher des entreprises dans une zone geographique ;
- verifier si un site officiel est trouve ;
- valider les resultats avant leur import ;
- preparer une preview commerciale statique depuis une fiche prospect validee ;
- publier une preview commerciale statique sur GitHub Pages pour partage par
  lien direct.

## Categories d'offres indicatives

- landing page ;
- site vitrine one-page ;
- site vitrine 3 a 5 pages ;
- refonte legere ;
- maintenance ou suivi ;
- developpement fullstack leger ;
- besoin a definir.

Ces categories aident au classement. Elles ne constituent ni un devis ni un
catalogue tarifaire contractuel.

## Fin du cycle CRM

Le suivi s'arrete lorsque le prospect passe au statut `gagne`. La gestion du
projet client commence en dehors du CRM.

## Hors perimetre initial

- enrichissement automatique ;
- envoi automatique d'emails ;
- connexion Gmail ;
- generation automatique par IA sans validation humaine ;
- production complete d'un site client avant accord commercial ;
- devis, facturation et comptabilite ;
- gestion des projets clients ;
- export comptable ;
- collaboration multi-utilisateur ;
- application mobile ;
- analyses statistiques complexes.

## Contraintes

- aucune relance apres une opposition explicite ;
- aucune donnee collectee ne vaut autorisation automatique de contacter ;
- toute information issue d'une recherche externe doit conserver sa source et
  sa date de verification ;
- l'absence de site trouve ne prouve pas l'absence de site.
- une preview commerciale ne constitue pas un contact commercial ;
- les previews publiees sont publiques et ne doivent contenir aucune donnee
  sensible, note interne, prix personnalise ou audit humiliant.
