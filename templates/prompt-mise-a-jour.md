# Prompt - Mise a jour d'un prospect

```text
Prospect : [NOM OU CHEMIN DE FICHE]

Evenement :
- type : [TYPE]
- date : [DATE ET HEURE]
- canal : [CANAL]
- fait : [DESCRIPTION FACTUELLE]
- resultat : [RESULTAT]
- prochaine action : [ACTION ET DATE, OU AUCUNE]

Mets a jour la fiche selon le pipeline et ajoute un evenement sans modifier
l'historique existant. Signale toute ambiguite avant d'appliquer une transition
irreversible.
```
