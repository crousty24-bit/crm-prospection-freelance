# Prompt - Etat operationnel

```text
Produis l'etat operationnel du [DATE] avec un horizon de [NOMBRE] jours.

Inclus :
- relances en retard ;
- actions dues aujourd'hui ;
- actions a venir ;
- prospects actifs sans prochaine action ;
- incoherences de statut, date ou historique.

Utilise uniquement les fiches de workspace/prospects comme source primaire et
enregistre le rapport dans workspace/rapports.
```
